# 📅 스마트 하이브리드 달력 앱 설계서 (v1.1)

본 문서는 음력·양력 병행 표기, 한국 특화 데이터(휴일, 절기), 그리고 알림 시스템을 포함한 달력 애플리케이션의 상세 설계서입니다.

---

## 1. 프로젝트 개요
* **프로젝트명**: 전통과 현대가 공존하는 스마트 하이브리드 달력 (Smart Hybrid Calendar)
* **플랫폼**: Flutter (Android, iOS)

* **주요 목표**: 
    * 한국의 전통 역법(음력, 24절기)의 정확한 제공.
    * 사용자 편의성을 극대화한 일정 등록 및 스마트 알림 기능 구현.

* **개발 목표**: 
    * 양력과 음력, 24절기를 완벽하게 지원하는 한국형 달력 구현.
    * 한국의 국경일, 휴일을 구현
    * 사용자 일정 등록 및 지능형 알림 시스템 구축.
    * AI와의 단계별 모듈형 코딩을 통한 빠른 프로토타이핑.

---

## 2. 핵심 기능 상세 설계

### 2.1. 하이브리드 캘린더 엔진 (Calendar Engine)
* **양력/음력 병행 표기**:
    * 음력 1일, 15일 등 주요 음력 날짜는 가독성을 위해 색상 변주.
    * 양/음력 병기
       **: 양력 날짜를 메인으로 하되, `korean_lunar_calendar`를 활용해 음력 날짜를 작게 표시.
    * 한국 특화 데이터
       **: 공공데이터포털 API를 연동하여 공휴일(대체 공휴일 포함) 및 24절기를 자동 반영.
       **공휴일**: 공공데이터포털 API를 연동하여 법정 공휴일 및 대체 공휴일 자동 반영 (빨간색 표시).
       **24절기**: 입춘, 우수 등 절기 데이터를 해당 날짜에 텍스트 아이콘으로 표시.
    * 시각화
       **: 일요일/공휴일(Red), 토요일(Blue), 평일(Black/White) 및 절기(Green) 아이콘 표기.

### 2.2. 일정 관리 및 알림 (Schedule & Notification)
    * 일정 등록 (CRUD):
    * 특정 날짜 클릭 시 일정 입력 모달(Modal) 활성화.
    * 제목, 메모, 시간대 설정 기능.
    * 제목, 메모, 시간, 알림 설정, 카테고리 색상 선택 기능.

    * 스마트 알림 시스템:
      **알림 시간 설정**: 정시, 10분 전, 30분 전, 1시간 전, 하루 전 등 사용자 선택 가능.
      **알림 시스템**: `flutter_local_notifications`를 사용하여 정시 또는 특정 시간(10분 전 등) 전에 푸시 알림 발송.
      **알림 유형**: 일반 일정 알림, 음력 기념일 리마인드(생신 등), 절기 당일 알림.

## 3. 기술 스택 (Tech Stack)
| 구분 | 기술 제안 | 비고 |
| :--- | :--- | :--- |
| **Framework** | Flutter (Dart) | 크로스 플랫폼 개발 |
| **State Management** | Riverpod | 앱 상태 및 API 데이터 관리 |
| **Local Database** | sqflite | 일정 및 캐시 데이터 저장 |
| **UI Components** | table_calendar | 커스텀 빌더를 통한 달력 구현 |
| **Notification** | flutter_local_notifications | 로컬 푸시 알림 |
| **External API** | 한국천문연구원 특일 정보 API | 공휴일 및 절기 데이터 확보 |

## 4. 데이터베이스 설계 (DB Schema)

```sql
CREATE TABLE schedules (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    memo TEXT,
    solar_date TEXT NOT NULL, -- YYYY-MM-DD
    time TEXT,                -- HH:mm
    is_lunar INTEGER DEFAULT 0,
    alarm_minutes_before INTEGER, 
    category_color INTEGER DEFAULT 0xFF2196F3
);
```

## 6. AI 협업 단계별 로드맵 (AI 프롬프트용)

### **Step 1: 데이터 모델 및 DB 구현**
> "플러터에서 `sqflite`를 사용하여 일정(제목, 메모, 날짜, 시간, 알림 설정)을 저장할 수 있는 모델 클래스와 DB 헬퍼 코드를 작성해 줘."

### **Step 2: 기본 달력 UI 및 음력 표시**
> "`table_calendar`와 `korean_lunar_calendar` 패키지를 사용하여, 각 날짜 셀에 양력과 음력이 함께 표시되는 커스텀 달력 UI를 만들어 줘."

### **Step 3: 외부 API 연동 및 휴일 표시**
> "공공데이터포털 API를 사용하여 한국 공휴일과 24절기 데이터를 가져와서 달력에 반영하는 로직을 작성해 줘. API 키는 변수로 처리해 줘."

### **Step 4: 일정 등록 및 알림 시스템**
> "사용자가 날짜를 클릭하면 일정을 등록하는 BottomSheet를 띄우고, `flutter_local_notifications`를 사용해 설정한 시간에 알림이 울리도록 구현해 줘."

## 7. UI/UX 가이드라인
1.  **가독성**: 양력과 음력이 겹쳐 보이지 않도록 적절한 폰트 크기 조절.
    **Dark Mode 지원**: 시스템 설정에 따른 자동 테마 전환.
2.  **색상 체계**: 일요일과 공휴일은 `Red`, 토요일은 `Blue`, 절기는 `Green` 계열의 보조색 사용.
3.  **인터랙션**: 
    * 날짜 롱 프레스(Long Press): 즉시 일정 등록 창 이동.
    * 스와이프(Swipe): 이전/다음 달 이동.
    *일정 표시**: 일정이 있는 날짜는 숫자 하단에 작은 점(Dot) 또는 바(Bar) 표시.
