까사음력달력

양력·음력 병행 표기, 한국 공휴일·24절기 연동,
일정 관리와 스마트 알림을 하나로

iOS 유료

주요 기능

🌙

양력·음력 병행 표기

매일 음력 날짜를 함께 표시하고, 음력 1일·15일 및 주요 명절을 강조합니다.

🎌

한국 공휴일·24절기

공공데이터포털 기반 공휴일, 기념일, 24절기를 자동으로 연동합니다.

📝

일정 관리 (CRUD)

날짜 탭 시 하단 인라인 패널에서 바로 일정을 확인하고 추가합니다.

🔁

반복 일정

매일·매월·매년 반복을 지원합니다. 음력 매년 반복은 양력 환산일에 자동 표시됩니다.

🔔

스마트 알림

정시·10분·30분·1시간·하루 전 알림 프리셋을 제공합니다.

🖼️

배경 이미지 커스텀

월별 달력 배경을 갤러리 사진으로 교체하거나 기본 이미지로 초기화할 수 있습니다.

색상 규칙

일요일 · 법정 공휴일 — 빨강
토요일 — 파랑
24절기 — 초록
음력 명절·전통 기념일 — 주황
평일 — 기본 흰색

데이터 및 개인정보

  • 모든 일정 데이터는 기기 내부에만 저장되며 외부 서버로 전송되지 않습니다.
  • 앱 삭제 시 기기에 저장된 모든 일정 데이터가 함께 삭제됩니다.
  • 공휴일·24절기 연동을 위해 공공데이터포털 API를 사용하지만, 개인식별 정보는 포함되지 않습니다.
  • 광고 네트워크, 분석 SDK, 외부 트래킹은 일절 사용하지 않습니다.
