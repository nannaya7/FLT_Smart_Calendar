개인정보 처리방침

스마트 하이브리드 달력  |  최종 업데이트: 2026년 5월 7일

본 앱은 사용자의 개인정보를 수집·저장·전송하지 않습니다. 모든 일정 데이터는 기기 내부에만 저장됩니다.

제1조 (개인정보의 수집 및 이용 목적)

스마트 하이브리드 달력(이하 "앱")은 개인식별 정보를 수집하지 않습니다. 앱은 사용자가 직접 입력한 일정(제목, 메모, 날짜, 시간)을 기기 내부 데이터베이스에만 저장하며, 해당 데이터는 외부 서버, 클라우드 또는 제3자에게 전송되지 않습니다.

제2조 (수집하는 정보의 항목 및 보유 기간)

항목 수집 주체 저장 위치 보유 기간
일정 데이터
(제목, 메모, 날짜, 시간, 알림 설정)		 사용자 직접 입력 기기 내부 (SQLite) 앱 삭제 시까지
배경 이미지 사용자 직접 선택 기기 내부 (앱 문서 폴더) 앱 삭제 시까지
API 키
(공공데이터포털, 선택 입력)		 사용자 직접 입력 기기 내부 (SharedPreferences) 사용자가 삭제하거나 앱 삭제 시까지
앱은 사용자 계정, 위치 정보, 연락처, 카메라 이미지(갤러리 선택 외), 식별자(IDFA, GAID 등)를 수집하지 않습니다.

제3조 (제3자 서비스 이용)

앱은 공휴일·24절기 정보 제공을 위해 아래 외부 API를 사용합니다. 해당 API 요청에는 개인식별 정보가 포함되지 않습니다.

  • 공공데이터포털 — 한국천문연구원 특일 정보 서비스
    연도별 공휴일·기념일·24절기 데이터를 조회합니다. 요청 시 사용자 API 키가 URL 파라미터로 포함되나, 개인정보는 전송되지 않습니다.
    운영 기관 개인정보처리방침: data.go.kr

광고 네트워크, 행동 분석 SDK, 외부 크래시 리포팅 도구는 사용하지 않습니다.

제4조 (알림 권한)

앱은 사용자가 설정한 일정 알림을 전송하기 위해 기기 알림 권한을 요청합니다. 알림은 기기 로컬에서만 생성되며 외부 서버를 경유하지 않습니다. 알림 권한을 거부하면 일정 알림 기능만 비활성화되고 그 외 기능은 정상 동작합니다.

제5조 (갤러리 접근 권한)

배경 이미지 교체 기능 사용 시 사진 라이브러리 접근 권한을 요청합니다. 선택한 이미지는 앱 내부 폴더에 복사되어 저장되며, 외부로 전송되지 않습니다. 권한을 거부하면 배경 이미지 교체 기능만 비활성화됩니다.

제6조 (아동의 개인정보 보호)

앱은 만 14세 미만 아동으로부터 의도적으로 개인정보를 수집하지 않습니다. 앱 자체적으로 개인정보를 수집하지 않으므로 연령 제한 없이 사용할 수 있습니다.

제7조 (이용자의 권리)

  • 앱 내 일정 데이터는 언제든지 삭제할 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 모든 데이터(일정, 배경 이미지, API 키)가 함께 삭제됩니다.
  • 개인정보 처리방침 관련 문의는 아래 이메일로 연락하시기 바랍니다.
